- The game should start with an empty board
- The first player is always the X player. A title should say whose turn it is: "It's X's turn" or "It's O's turn"
- When a player clicks a cell, the cell should be filled with the player's symbol (X or O), and the turn should be
  passed to the other player
- When a player wins the game, a message should say who won the game: "Player X wins!" or "Player O wins!" The remaining
  cells should be disabled
- When all the cells are filled and neither player has won, a message should say that the game ended in a draw: "It's a
  draw!"
